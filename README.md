# Everhush_first-project

Nombre del juego: Everhush 🪸🫧

Género y plataforma: Videojuego de plataformas 2D con elementos de exploración y aventura, pensado para PC.

Mecánica principal: El jugador explorará un mundo submarino fantástico, recorrerá plataformas y descubrirá ruinas y lugares ocultos

Motor de desarrollo: Unity, utilizando C# para la programación de las mecánicas y los elementos interactivos del juego.
